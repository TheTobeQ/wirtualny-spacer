# Wirtualny spacer 3D

Interaktywny spacer po apartamencie (Three.js + model GLB).

## Uruchomienie lokalne

```bash
python3 -m http.server 8765
```
Następnie otwórz: http://localhost:8765

## Sterowanie

- **Desktop:** kliknij „Rozpocznij spacer” → WASD + mysz
- **Telefon:** joystick (lewy dół) + przeciąganie (prawa strona)

## Pliki

- `index.html` – viewer
- `apartment.glb` – model 3D (Twój oryginalny układ)
